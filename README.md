# HPG Math Playground

Interactive toys that go with [HPG Math](https://www.youtube.com/@HPGMath) videos. Each one is a single HTML file: no build step, no login, no tracking.

Live: https://qiqs00.github.io/hpg-math-playground/

| Episode | Toy |
|---|---|
| EP01 · Slow, Then Sudden | [Can you stop it at half full?](https://qiqs00.github.io/hpg-math-playground/ep01-pond/) |

Run locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
